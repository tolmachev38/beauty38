# Сайт студии красоты Елены Толмачевой — beauty38.ru

Статический сайт на GitHub Pages + админка, которая редактирует всё содержимое и публикует изменения прямо в этот репозиторий через токен GitHub.

- Сайт: https://beauty38.ru/
- Админка: https://beauty38.ru/admin/

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Готовая страница сайта. **Руками не править** — админка пересобирает её при каждой публикации. |
| `content/site.json` | Все данные сайта: тексты, цены, фото, контакты, SEO, музыка, цвета. Источник истины. |
| `core/render.js` | Сборщик: превращает `site.json` в `index.html`, `404.html`, `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt`, `site.webmanifest`, `CNAME`. |
| `admin/` | Админка (открывается по адресу `/admin/`). |
| `assets/css`, `assets/js`, `assets/fonts` | Стили, скрипт и шрифты сайта. |
| `assets/img` | Фотографии (WebP). Новые фото админка кладёт сюда же. |
| `assets/audio` | Музыка сайта. |
| `tools/build.js` | Сборка без админки: `node tools/build.js`. |
| `*.txt` из 32 символов | Ключ IndexNow — не удалять (по нему Яндекс и Bing принимают уведомления об обновлении). |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages. |

## Загрузка в репозиторий

**Вариант А — в существующий репозиторий, который уже обслуживает beauty38.ru (рекомендуется).**

1. Откройте репозиторий на GitHub → **Add file → Upload files**.
2. Откройте папку `ИТОГ` на компьютере, выделите **всё содержимое** (Ctrl+A) — именно файлы и папки внутри, а не саму папку `ИТОГ` — и перетащите в окно браузера.
3. Внизу нажмите **Commit changes**. Старый `index.html` заменится новым.
4. **Settings → Pages**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`. Custom domain — `beauty38.ru`, галочка **Enforce HTTPS**.

**Вариант Б — через git.**

```bash
git clone https://github.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ.git
```
Скопируйте содержимое `ИТОГ` в папку клона с заменой файлов, затем:
```bash
git add -A
git commit -m "Сайт с админкой"
git push
```

## Токен для админки

GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:

- **Repository access:** *Only select repositories* → репозиторий сайта.
- **Permissions → Repository permissions → Contents: Read and write** (обязательно).
- **Pages: Read-only** — по желанию, чтобы админка показывала статус сборки.
- Срок действия — на ваше усмотрение (например, год). Когда истечёт — выпустите новый и войдите заново.

## Вход в админку

1. Откройте https://beauty38.ru/admin/
2. Репозиторий — `владелец/название` (или ссылка на репозиторий), ветка — `main`, токен — `github_pat_…`.
3. «Запомнить на этом устройстве» — токен останется только в этом браузере.

Чтобы не вводить репозиторий каждый раз, впишите его в `admin/config.json` (поля `owner`, `repo`). После первой публикации админка заполнит этот файл сама.

## Как работает публикация

Кнопка «Опубликовать» (или Ctrl+S) собирает сайт в браузере и отправляет **один коммит** только с изменившимися файлами. GitHub Pages обновляет сайт за 1–2 минуты. Через 2 минуты админка уведомляет Яндекс и Bing через IndexNow.

История версий — раздел «История версий»: любую прошлую версию можно загрузить в редактор и опубликовать снова.

## Подстановки в текстах

`{{phone}}`, `{{phoneHref}}`, `{{phoneLink}}`, `{{phone2}}`, `{{phone2Href}}`, `{{telegramHref}}`, `{{whatsappHref}}`, `{{maxHref}}`, `{{twogisHref}}`, `{{yandexMapsHref}}`, `{{city}}`, `{{street}}`, `{{address}}`, `{{hours}}`, `{{year}}`, `{{brand}}` — подставляются из раздела «Контакты». Меняете телефон в одном месте — он меняется везде.

## Домен и DNS

DNS beauty38.ru уже настроен на GitHub Pages (A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`). Для IPv6 можно добавить AAAA-записи `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`.

Домен меняется в админке: «SEO и нейропоиск» → «Домен сайта». Из него собираются canonical, sitemap, robots, разметка, llms.txt и `CNAME`.

## Безопасность

- Админка открыта всем, но без токена ничего сделать нельзя: данные читаются и пишутся только через GitHub API с вашим токеном.
- Токен не попадает в репозиторий и уходит только на `api.github.com`.
- `/admin/`, `/content/`, `/core/`, `/tools/` закрыты от индексации в `robots.txt`, у админки стоит `noindex`.
- Потеряли доступ к устройству — отзовите токен в GitHub (Settings → Developer settings).
